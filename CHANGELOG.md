## 1.0.0

* Initial release of `app_bar_ui` — a reusable, production-ready Flutter package providing a Scroll-Responsive UI System.
* Feature: Fully scrollable header supporting titles, subtitles, welcome banners, profile info, and custom widgets.
* Feature: Independently pinned left and right side action icons with zero background, elevation, cards, or borders.
* Feature: Dual-state synchronized icon transitions (e.g. Left Profile Avatar -> Drawer Button, Right Notification -> Profile Avatar) with fade, scale, and subtle slide animations.
* Feature: Mobile System Status Bar visibility coordination with threshold-based hysteresis and content jump prevention.
* Feature: Support for both continuous scroll progress mapping and threshold-triggered animation controller modes.
* Feature: Zero-lag performance engine using targeted listenable notifications to avoid rebuilding scrollable body content.
* Feature: Comprehensive unit and widget test suite covering all configurations, interactions, and edge cases.
* Feature: Fully featured interactive example application with live transition telemetry and config controls.
